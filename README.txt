GALLERY DOT — SP版デモLP

【ファイル】
index.html / style.css / script.js / images/

【開き方】
index.html をブラウザで開いてください。
VS Code の Live Server を利用すると安定して確認できます。

【実装済み】
・スマートフォン最適化
・スクロール表示アニメーション
・ヒーロー画像ズーム
・ドロワーメニュー
・作品モーダル表示
・在庫カウントアップ
・FAQアコーディオン
・予約フォームの入力チェック
・デモ完了モーダル

【注意】
予約フォーム、LINE、在庫情報、QR発行はUIデモです。
本番運用には外部予約サービスまたはバックエンド/APIとの連携が必要です。
Google Fontsを使用するため、フォント表示にはインターネット接続が必要です。
